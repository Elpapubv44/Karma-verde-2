GUÍA DE IMPLEMENTACIÓN LOCAL Y USO DE IA (GEMINI API) PARA SERVIDOR PROPIO
Proyecto: Karmaverde - Escáner e Investigador Inteligente de QR

1. ¿CÓMO FUNCIONA EL CONSUMO DE TOKENS / IA?
--------------------------------------------------------------------------------
- En este entorno de desarrollo (Google AI Studio Build), la variable de entorno
  GEMINI_API_KEY se suministra automáticamente por la plataforma.
- Cuando exportes este proyecto a tu propia computadora, servidor VPS o red local (LAN)
  para usarlo desde tu celular (ej. http://192.168.1.XX:3000):
  * MODO HÍBRIDO OFFLINE (Sin costo / Sin API key):
    El código ya viene preparado con un fallback inteligente (`generateLocalAnalysis`).
    Si no configuras ninguna API Key en local, el escáner IGUAL responderá de forma
    instantánea desglosando URLs, Wikipedias, materiales PET/PEAD/Cartón/Aluminio
    sin gastar un solo token ni internet.
  * MODO IA COMPLETO (Con Gemini):
    Solo necesitas obtener una API Key gratuita de Google AI Studio y colocarla en
    tu archivo `.env` local.


2. PASOS PARA CORRERLO EN TU SERVIDOR LOCAL Y USARLO DESDE EL CELULAR
--------------------------------------------------------------------------------

Paso A: Obtener tu API Key gratuita de Google (opcional para IA en vivo)
1. Entra en https://aistudio.google.com/app/apikey con tu cuenta de Google.
2. Haz clic en "Create API key".
3. Copia la clave alfanumérica generada.

Paso B: Configuración del archivo de entorno en tu servidor local
1. En la raíz de tu proyecto (donde está package.json), crea o edita el archivo `.env`:
   
   GEMINI_API_KEY=tu_api_key_de_gemini_aqui
   PORT=3000

Paso C: Instalar dependencias e iniciar el servidor
1. Abre tu terminal en la carpeta del proyecto y ejecuta:
   npm install
   npm run build
   npm run start   (o `npm run dev -- --host` para desarrollo en red local)

Paso D: Conectar el Celular por Wi-Fi
1. Averigua la IP local de tu PC/servidor (ej. `ipconfig` en Windows o `ifconfig` en Linux/Mac).
   Ejemplo de IP: `192.168.1.45`
2. En el navegador de tu celular (Chrome / Safari / Brave), ingresa a:
   http://192.168.1.45:3000
3. Dale permisos de cámara al navegador cuando entres a `/alumno/escaner` o usa el cuadro de
   texto para pegar URLs de wikis, papers o códigos de barras.


3. CÓDIGO BACKEND INDEPENDIENTE (Node.js / Express / TypeScript)
--------------------------------------------------------------------------------
Si quieres aislar la función de análisis IA en cualquier otro backend (Express, Fastify, etc.):

```typescript
import { GoogleGenAI } from "@google/genai";

export async function analyzeQrWithGemini(code: string, apiKey: string) {
  const ai = new GoogleGenAI({ apiKey });

  const prompt = `
Analiza el siguiente contenido extraído de un código QR, URL de Wikipedia, paper o residuo: "${code}".
Retorna estrictamente un objeto JSON con este formato:
{
  "objeto": "Nombre del objeto, paper o sitio web",
  "origen": "Fuente, dominio o procedencia institucional",
  "tipoMaterial": "Material detectado o Formato Digital",
  "reciclabilidad": "Alta / Media / Informativo / Académico",
  "descripcion": "Resumen conciso y pedagógico (2-3 oraciones) sobre el contenido.",
  "impactoEstimado": "Dato curioso o cálculo de impacto ambiental / valor científico.",
  "consejo": "Recomendación práctica para el alumno."
}`;

  const response = await ai.models.generateContent({
    model: "gemini-3.7-flash",
    contents: prompt,
    config: {
      responseMimeType: "application/json",
    },
  });

  return JSON.parse(response.text || "{}");
}
```

4. CÓDIGO BACKEND EQUIVALENTE EN PHP (Para tu servidor XAMPP / Apache)
--------------------------------------------------------------------------------
Si prefieres que corra sobre tu stack PHP/MySQL en XAMPP:

```php
<?php
header('Content-Type: application/json; charset=utf-8');

$input = json_decode(file_get_contents('php://input'), true);
$code = $input['code'] ?? '';
$apiKey = getenv('GEMINI_API_KEY') ?: 'TU_API_KEY_AQUI';

if (empty($code)) {
    http_response_code(400);
    echo json_encode(['error' => 'Código requerido']);
    exit;
}

$prompt = "Analiza el siguiente contenido de un código QR o URL: \"$code\". Responde únicamente un JSON con los campos: objeto, origen, tipoMaterial, reciclabilidad, descripcion, impactoEstimado, consejo.";

$url = "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=" . $apiKey;

$payload = [
    "contents" => [
        ["parts" => [["text" => $prompt]]]
    ],
    "generationConfig" => [
        "response_mime_type" => "application/json"
    ]
];

$ch = curl_init($url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($payload));
curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
$result = curl_exec($ch);
curl_close($ch);

$resData = json_decode($result, true);
$rawText = $resData['candidates'][0]['content']['parts'][0]['text'] ?? null;

if ($rawText) {
    echo json_encode(['source' => 'gemini', 'analysis' => json_decode($rawText, true)]);
} else {
    echo json_encode(['source' => 'local', 'analysis' => ['objeto' => 'Enlace detectado', 'descripcion' => 'Contenido: ' . $code]]);
}
?>
```

5. RESUMEN DE VENTAJAS DE ESTA ARQUITECTURA
--------------------------------------------------------------------------------
- Cero caídas: Si no hay internet en la escuela, el motor de fallback local responde.
- Bajo consumo de tokens: Se usa el modelo Flash (el más rápido y eficiente).
- Funciona en móvil: Solo necesitas conectar el celular a la misma red Wi-Fi que la PC.
